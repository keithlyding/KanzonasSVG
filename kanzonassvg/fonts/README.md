# Icon font

`materialdesignicons6-webfont-6.9.96.ttf`: Material Design Icons 6.9.96
(https://github.com/Templarian/MaterialDesign), unchanged, as shipped in the qtawesome 1.4.0
package on PyPI (`qtawesome/fonts/`). Licensed under the Apache License, Version 2.0
(`LICENSE-Apache-2.0.txt`). The ribbon's icons are drawn from it (`kanzonassvg/icons.py`, which
lists the places in the font of the icons it uses, taken from the font's character map,
`materialdesignicons6-webfont-charmap-6.9.96.json` in the same package), as KanzonasPDF's are.
